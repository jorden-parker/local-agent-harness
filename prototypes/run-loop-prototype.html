Run Loop Prototype

Question being prototyped: when a small local model asks the Harness to run a tool, the Harness checks Confinement (paths inside the Target Directory, no secret files, no protected files, no denylisted shell commands), then asks the human for Confirmation (y / n / a), then runs the tool and feeds the result back. Failures go back to the model as text. Three consecutive failures, 50 iterations, or a plain text reply end the Run. Does that sequence feel right once you push odd cases through it?
