## Findings considered and rejected

- Unbounded `grep` regex (S-07, ReDoS-style hang): low impact, local self-DoS only; not selected 2026-10-19.
- Shell inherits the full user environment (S-06): gated by Confirmation; an env allowlist risks breaking tools. Revisit with the sandbox idea.
- Run logs persist secret contents read under `--allow-secrets`: logs are local and git-ignored; by design.
- Model-written summaries of old turns (LLM compaction): an extra slow local inference per compaction and weak small-model summaries; 007 uses deterministic observation masking instead.
- Multi-turn chat mode (continue a Run after the final answer): `GLOSSARY.md` defines a Run as one task, and the TUI research settled on a one-shot design.
- Real OS sandbox for `shell` (direction D-04, 2026-10-19): grounded (glossary reserves "Sandbox" for later), but L effort and platform-specific; not selected this round.
- Loading the target repo's `AGENTS.md`/`CLAUDE.md` into the system prompt (D-06): deferred until 002's usage data shows how much window it would cost.

- Full-screen TUI (Ink 8, OpenTUI, blessed): still rejected as the main view; 011 uses Ink 8 inline (`<Static>` into scrollback) and only the opt-in transcript uses the alternate screen. Originally rejected by `docs/research/tui-libraries.md` and `agent-tui-patterns.md`; a one-shot Run fits the inline/scrollback family, OpenTUI needs Node 26.4+, blessed is stale.
- Lowering the 80-line gate preview cap: without an expand key the user would approve diffs they cannot see; keep the cap until a `v`-to-expand affordance exists.
- A `--target <dir>` flag or prompting for the task when `harness` is run bare (2026-10-19): the operator chose PATH linking plus `INIT_CWD` only, with no new flags.
